# EthicsGovern-NG

**An Explainable AI Governance Framework and Policy Enforcement Dashboard for Nigerian Banks**

Code, synthetic data and database dump for the Professional Master's project of Habeeb Kazeem
(Master of Information Technology, School of Computing, Miva Open University, Abuja; matric 2025/B/MIT/1039).

All data in this repository is synthetic. No real customer, bank or participant data was used or collected.

## What it is

EthicsGovern-NG turns written AI governance policy into executable checks for a bank's models:

* **Fairness:** demographic parity difference, disparate impact ratio and equal opportunity difference, with confidence intervals.
* **Explainability:** SHAP and LIME explanations for individual decisions, generated asynchronously.
* **Drift:** two-sample Kolmogorov–Smirnov and chi-squared tests with Benjamini–Hochberg correction.
* **Policy as code:** thresholds and rules written in Rego and evaluated by Open Policy Agent, producing findings with severity and a named owner.
* **Maturity model:** five levels, seven weighted dimensions, overall level capped at the weakest dimension plus one.
* **Risk taxonomy:** 28 AI ethics risks mapped to Nigerian instruments, control owners, detection methods and evidence (`data/risk_taxonomy.json`).

## Quick start (Windows)

1. Install Python 3.12 (tick *Add python.exe to PATH*).
2. Download this repository (green *Code* button, then *Download ZIP*) and unzip it.
3. Double-click `run.bat`. The first run needs internet: it installs the packages and downloads the Open Policy Agent binary.
4. Open http://127.0.0.1:8000 and sign in with a demonstration account listed in `docs/PROTOTYPE_GUIDE.md`.

Run the tests with `run_tests.bat`, or `python -m pytest` in an activated environment.

## Rebuilding the database

    python -c "import sqlite3; c=sqlite3.connect('rebuilt.db'); c.executescript(open('database/ethicsgovern_demo_dump.sql').read())"

## Re-running the experiments

`scripts/run_e1.py`, `run_e2.py`, `run_e3.py` (application running), `run_e4.js`, `run_supplementary.py`, `run_review_additions.py` and `run_policy_version_proof.py` write their results to `docs/results/`. Latency (E3) depends on the machine.

## Limitations

This is a research prototype, not a production system. It has no TLS, no encryption at rest, no tamper-evident log and no rate limiting. The demonstration accounts use published demonstration passwords and must never be reused. All results come from synthetic data generated by a single generator, and usability with people was not tested.
