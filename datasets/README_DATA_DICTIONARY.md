# EthicsGovern-NG: synthetic datasets used in the evaluation

**Every record here is synthetic.** No real person, customer, bank or participant is represented.
No human participants took part in any experiment; E2 and E4 were carried out as computed and scripted studies (see sections 5.2.2 and 5.2.4 of the report, Appendix J).

## Loan datasets (E1, training, E2 applicants)

Generated by `generate_synthetic.py` (`generate(n, bias, seed)`).

| Column | Meaning |
|---|---|
| `age` | Years, uniform 21 to 64 |
| `income` | Annual income in naira, log-normal, median N3.2 million, log-sd 0.65 |
| `credit_score` | Normal(640, 90), clipped to 300 to 850 |
| `loan_amount` | Naira; income x Uniform(0.20, 1.40), clipped to N50,000 to N20,000,000 |
| `gender` | `M` or `F`, 55% / 45% |
| `decision` | Historical approval (1) or decline (0). Drawn from the latent probability, **reduced by a factor (1 - bias) for female applicants** |
| `repaid` | Whether the applicant would in fact repay (1/0), drawn from the *unbiased* latent probability. Ground truth for equal opportunity |
| `p_true` | The unbiased latent approval probability. **Withheld from the models and from the monitoring engine**; kept so that the bias present is known exactly |

Latent probability: `1 / (1 + exp(-z))`, with `z = 1.0 + 0.0060 (credit_score - 640) + 0.55 ln(income / 3.2m) - 1.30 (loan_amount / income) + 0.012 (age - 40)`.
The intercept (+1.0) differs from the value printed in the first draft of Appendix A (-3.4), which approved only about 1.6% of applicants.

### E1 file names and seeds
`loans_bias{0|5|10|20|30}_run{0..9}.csv`: bias level is the percentage reduction in female approval probability; run *r* uses seed `1000 + r`.
Truth label for each dataset: *biased* if the ratio of expected approval rates (female over male, from `p_true` and the injected reduction) is below 0.80.
Regenerating a file with the same level and seed reproduces it exactly (verified for all 50).

### Training data
`train_unbiased.csv`: bias 0, seed 1 (used for loan-scorer-v2 and as the explanation background sample). `train_biased.csv`: bias 0.25, seed 2 (used for loan-scorer-v1).

### E2 applicants
`e2_applicants.csv`: the first 500 rows of `generate(n=2000, bias=0, seed=31337)`.

## E2 per-decision table (`e2_explanations.csv`)

One row per applicant per model (`v1` = trained on biased history, `v2` = trained on unbiased history).

| Column group | Columns |
|---|---|
| Identity and inputs | `model`, `applicant_id`, `age`, `income`, `credit_score`, `loan_amount`, `gender_f` |
| Decision | `score` (model probability), `prediction` (1 = approve at 0.5) |
| Attributions | `shap_<feature>` (log-odds units), `lime_<feature>` (probability units) for the five features |
| Faithfulness | `shap_additivity_error`, `lime_surrogate_r2`, `delta_remove_top_shap`, `delta_remove_top_lime`, `delta_remove_random`, `delta_remove_global_top` (absolute change in score when the named feature is removed by marginalising over 50 background applicants) |
| Agreement | `top3_overlap` (share of the SHAP top three also in the LIME top three), `top1_match`, `sign_agreement`, `rank_corr_shap_lime` |
| Stability | `shap_stability_rank_corr`, `shap_top3_stable` (after small input perturbations), `lime_stability_rank_corr`, `lime_top3_stable` (re-run with a different random seed), `decision_flipped_by_perturbation` |
| Concision and exposure | `shap_top3_share`, `gender_in_shap_top3`, `gender_in_lime_top3`, `gender_share_shap`, `n_adverse_factors_shap` |

## E3 latency (`e3_raw_latency.csv`)
`direct_ms`: request straight to the Model API. `proxy_ms`: same payload through the monitoring proxy (authentication, forwarding, decision log, explanation enqueue). Requests were interleaved, after 100 warm-up requests, from one client with persistent connections. Measured on a 2-core Linux virtual machine; re-run on your own hardware (`scripts/run_e3.py`) before quoting.

## E4 scripted task study
`e4_task_results.csv`: `run` (1 to 5 automated runs, each from freshly reset demo data), `task` and `variant` (T1 to T5; T2 variant a = applicant among the 40 most recent decisions, b = applicant outside them), `outcome`, `success` (checked against the system's own records, not against the agent's own report), `subgoals`, `clicks`, `keystrokes`, `reads`, `screens`, `klm_seconds`, `errors`, `note`.
`e4_action_log.csv`: every logged action with its Keystroke-Level-Model operator and time (M mental 1.35 s, P pointing 1.1 s, B button 0.1 s, K keystroke 0.28 s, H homing 0.4 s).
The agent follows the shortest known path, so the predicted times are expert-user lower bounds, not measurements of people.

## supplementary.json
Produced by `scripts/run_supplementary.py` (prototype). `noise_by_window`: SD and percentiles of the observed disparate impact ratio for 300 datasets at each window size with 20% bias (Table 5.4). `false_alarms_clean_model`: 200 windows of 2,400 decisions from loan-scorer-v2. `explanation_cost_ms`, `other_timings_ms`: in-process timings (machine dependent). `reason_codes_citing_gender`: declined applicants whose three most adverse SHAP factors include gender (Table 5.7). `sign_agreement_excluding_gender`: Table 5.6.
